Automatyczne dociąganie odsłuchów

Co godzinę GitHub Actions pyta Spotify o ostatnie 50 utworów każdego podłączonego konta i dopisuje nowe do gałęzi dane. Strona łączy je z eksportem.

Połącz swoje konto Spotify

Zaloguj się, a potem wyślij kod osobie, która dała Ci ten link. Spotify pozwoli na to tylko wtedy, gdy ta osoba dopisała już Twój e-mail w swojej aplikacji.

Przekaż kod (ważny ok. 10 minut)

Zalogowano. Twój kod:

  1. Otwórz workflow „Spotify – dociąganie odsłuchów”.
  2. Kliknij Run workflow (po prawej), wklej kod, wybierz konto 1, opcjonalnie wpisz nazwę i kliknij zielone Run workflow.
  3. Po ok. minucie odśwież tę stronę — konto powinno być zielone.

Wyślij ten kod osobie, która dała Ci link — ona wklei go u siebie. Jeśli nie zdąży w 10 minut, po prostu zaloguj się jeszcze raz.

Konfiguracja (jednorazowo, robi to właściciel)

  1. Na developer.spotify.com/dashboard kliknij Create app. W Redirect URIs wklej dokładnie: kliknij Add, zaznacz Web API, zaakceptuj warunki i Save. Spotify wymaga, żeby właściciel aplikacji miał Premium.
  2. Z Settings aplikacji skopiuj Client ID i Client secret do sekretów repo jako SPOTIFY_CLIENT_ID i SPOTIFY_CLIENT_SECRET.
  3. Zaloguj się jako konto:
  4. Po powrocie pojawi się kod do wklejenia w Run workflow.

Dodanie znajomego (konta 2–5)

  1. W swojej aplikacji na developer.spotify.com → User Management dopisz imię i e-mail jego konta Spotify (limit Spotify: 5 osób łącznie z Tobą).
  2. Wyślij mu link spotify.html?konto=2 (numer = wolne miejsce). Zaloguje się i odeśle Ci kod.
  3. Wklej kod w Run workflow, wybierz to samo konto i wpisz jego imię.

Odłączenie: Run workflow → wybierz konto → zaznacz „Odłącz to konto”. Logowanie wygasa po ok. 6 miesiącach — strona statystyk przypomni.
