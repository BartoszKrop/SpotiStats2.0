Krok 4 — przekaż kod do GitHuba (masz 10 minut)

Zalogowano. Skopiuj kod:

  1. Otwórz workflow „Spotify – dociąganie odsłuchów”.
  2. Kliknij Run workflow (po prawej), wklej kod w pole i kliknij zielone Run workflow.
  3. Po ok. minucie odśwież tę stronę — stan powinien być zielony.

Konfiguracja (jednorazowo)

  1. Wejdź na developer.spotify.com/dashboard, zaloguj się i kliknij Create app. Nazwa i opis dowolne (np. „SpotiStats”). W Redirect URIs wklej dokładnie:
    i kliknij Add. W „Which API/SDKs are you planning to use?” zaznacz Web API, zaakceptuj warunki i Save. Spotify wymaga, żeby właściciel aplikacji miał Premium.
  2. W aplikacji wejdź w Settings, skopiuj Client ID i (po kliknięciu „View client secret”) Client secret. Na GitHubie otwórz Settings → Secrets and variables → Actions i dodaj dwa sekrety przyciskiem New repository secret: SPOTIFY_CLIENT_ID oraz SPOTIFY_CLIENT_SECRET.
  3. Wklej tu Client ID (sekretu tu nie podawaj) i zaloguj się:
  4. Po powrocie pojawi się kod do przekazania GitHubowi (karta wyżej).
