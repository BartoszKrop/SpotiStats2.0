      Zapis na GitHubie

      Eksport zapisze się w repozytorium (gałąź dane) i będzie wczytywał się sam na każdym urządzeniu, bez ponownego wgrywania. Uwaga: dane (utwór, wykonawca, album, godzina) będą publiczne — tak samo jak odsłuchy z automatu.

      1. Otwórz tworzenie tokenu na GitHubie.
      2. Nazwa dowolna, ważność np. rok. Repository access → Only select repositories → SpotiStats2.0.
      3. Permissions → Repository permissions → Contents → Read and write. Kliknij „Generate token” i skopiuj go.
      4. Wklej token poniżej. Zostaje tylko w tej przeglądarce (nikt inny go nie zobaczy).

      Wczytuję Twoją historię…

      Wczytaj swoją historię ze Spotify

      Poproś o „Rozszerzoną historię strumieniowania” (Extended streaming history) na spotify.com → Konto → Prywatność. Spotify wyśle maila z plikiem .zip — wrzuć go tutaj w całości.

      Eksport zostaje w tej przeglądarce i wczytuje się sam przy każdym wejściu — wgrywasz go tylko raz. Eksport nigdzie nie jest wysyłany. Jedynie nazwy wykonawców i albumów trafiają do publicznego API Deezera, by pobrać zdjęcia i okładki.

      Wskazówka: otwórz stronę w zwykłej przeglądarce (Safari / Chrome), a nie z okienka innej aplikacji, i dodaj ją do ekranu głównego — wtedy dane na pewno zostają.
